**Description (product page):**

### One codebase. Front-of-house + back-of-house + management.

Modern, production-ready management system for restaurants, cafés, resorts, and recreation venues.

**Front of house**
- Point of Sale (dine-in / takeaway), smart cart, cash calculation, ESC/POS receipt printing
- QR code per table — guest orders from phone, no app needed
- Online reservation (gazebos, tables, day-use) + coupons
- Online payment via Tripay (VA, QRIS, retail, e-wallet)

**Back of house**
- Kitchen Display System — real-time paid-order queue, bump timer
- Inventory: warehouse + café stock, in/out/adjust transactions, low-stock alerts, daily stock
- Ticketing cashier (attraction tickets) separate from POS

**Management**
- Financial reports: ledger, P&L, comprehensive / cafe / inventory / reservation (PDF & Excel)
- BI dashboard: HPP (COGS), revenue trends, KPIs, decision center
- Roles: admin / manager / staff / customer / guest (Spatie Permission)
- Printable invoices, email + WhatsApp notification templates

**Tech**
Laravel 12 · Inertia.js · React 19 · Tailwind CSS · MySQL · Redis (optional) · Laravel Reverb · Tripay

**What's included**
- Full source code (no venue branding — generic demo data)
- `.env.example`, README (EN/ID), INSTALL (EN/ID), CHANGELOG, LICENSE (MIT) + LICENSE_TIERS
- Seeders for roles, demo settings, demo menu
- Git tag `v1.0.0`

**Install in 5 minutes**
```bash
composer install && npm install
cp .env.example .env && php artisan key:generate
php artisan migrate --seed
npm run build
php artisan serve
```

**Requirements:** PHP 8.2+, MySQL 8 / MariaDB, Node 20+, Composer 2.
