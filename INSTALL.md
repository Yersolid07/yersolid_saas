# Installation Guide — English

This package ships as a clean Laravel 12 + Inertia (React 19) codebase. No venue-specific data,
photos, or credentials are bundled — demo content is generic and generated by seeders.

## Requirements
- PHP >= 8.2 (tested with PHP 8.4)
- MySQL 8 / MariaDB 10.6+ (or SQLite for quick local test)
- Node.js >= 20
- Composer 2
- Redis (optional, for cache/broadcast; falls back to database cache if absent)

## Steps

1. **Install dependencies**
   ```bash
   composer install
   npm install
   ```

2. **Environment setup**
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```
   Edit `.env`:
   - `APP_URL` — your domain
   - `DB_*` — your database credentials
   - `TRIPAY_*` — (optional) Tripay payment gateway keys if you want online payment

3. **Database**
   ```bash
   php artisan migrate --seed
   ```
   Seeds create roles/permissions, demo settings, and demo users with **example.com** emails
   (password is the default `password` for demo — change immediately).

4. **Frontend build**
   ```bash
   npm run build
   ```

5. **Storage link (for uploaded images)**
   ```bash
   php artisan storage:link
   ```

6. **Serve**
   ```bash
   php artisan serve
   ```
   Or configure nginx/vhost to point at `public/`.

## Production notes
- Set `APP_ENV=production`, `APP_DEBUG=false`.
- Queue worker: `php artisan queue:work` (or use `ecosystem.config.cjs` with pm2).
- Scheduler: `php artisan schedule:work`.
- Reverb (websockets, optional): `php artisan reverb:start`.
- HTTPS via Cloudflare or Let's Encrypt; set `SESSION_SECURE_COOKIE=true` only over HTTPS.

## First login
After `php artisan migrate --seed`, log in with the demo admin created by `AdminUserSeeder`
(email ends in `@example.com`, password `password`). Change the password and email immediately.
